# LokNigrani – Transparent Infrastructure for a Better Tomorrow (Part 1: Layout + Dashboard)
1. Run `npm install` to install dependencies.
2. Run `npm run dev` and open the printed local URL.
3. Mock data lives in `src/data/*.js`; nav and risk colors in `src/config.js`.
4. All sidebar pages are routed; unbuilt pages show a placeholder.
5. Stack: React 18, Vite, Tailwind, React Router, Recharts, react-leaflet (OpenStreetMap).
